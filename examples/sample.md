# LM358 Dual Operational Amplifier - Datasheet Summary

## Description
The LM358 series consists of two independent, high-gain, internally frequency-compensated
operational amplifiers designed to operate from a single power supply.

## Key Specifications
| Parameter | Min | Typical | Max | Unit |
|-----------|-----|---------|-----|------|
| Supply Voltage | 3.0 | - | 32 | V |

| Gain Bandwidth Product | - | 1.1 | - | MHz |

## Pin Configuration (SOIC-8)
- Pin 1: Output A
- Pin 2: Inverting Input A
- Pin 3: Non-inverting Input A
- Pin 4: GND
- Pin 5: Non-inverting Input B
- Pin 6: Inverting Input B
- Pin 7: Output B
- Pin 8: VCC
