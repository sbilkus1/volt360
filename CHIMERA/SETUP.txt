============================================================
  CHIMERA — First-Time Setup Guide
  ONE-TIME setup after downloading UE 5.3+
============================================================

=== PREREQUISITES ===
1. Windows 10/11 64-bit, 32GB RAM, SSD, DX12 GPU
2. Visual Studio 2022 with "Game Development with C++" workload
3. UE 5.3 or 5.4 installed via Epic Launcher
4. ~100GB free disk space for engine + assets

=== STEP 1: Open the project ===
Double-click CHIMERA.uproject
If it asks to rebuild modules: click Yes
First compile will take 10-20 minutes on first run.
Fix any compile errors (typically missing #includes for engine headers).

=== STEP 2: Run the asset downloader ===
Open PowerShell in this folder:
  PowerShell -ExecutionPolicy Bypass -File .\DownloadAssets.ps1

=== STEP 3: Download free 3D assets ===
A) Quixel Megascans (in UE5, free):
   UE5 Editor > Window > Quixel Bridge > Sign in (Epic account)
   Click "Download All" for Surfaces, 3D Assets, Decals, 3D Plants
   ~50GB, all photorealistic scanned, free with UE5 license

B) UE Marketplace Free Packs (in Launcher, free):
   Launcher > Unreal Engine > Marketplace > Filter: Free
   Search and Add to Project:
   - City Sample Buildings (urban architecture)
   - Modular SciFi (cyberpunk corridors/props)
   - Modular Fantasy (castle walls, medieval props)
   - Rural Australia (farm buildings, fences)
   - Vehicle Variety Pack (cars, trucks, bikes)
   - Hospital Interior Pack (beds, OR equipment)
   - Police Station Props (desks, cells, lockers)
   - Medieval Environment (castles, villages)
   ~25GB

C) Sketchfab CC0 3D models (sketchfab.com, free):
   Search with filters: Downloadable + CC0 + FBX format
   Key searches:
   - "police station building"
   - "modern hospital exterior"
   - "fantasy castle medieval"
   - "cyberpunk building"
   - "dragon 3d model"
   - "mountain village"
   - "seaside town architecture"
   After downloading, drag FBX files into:
     Content/Imported/
   UE5 auto-imports as StaticMesh + Material assets.

D) Poly Haven (polyhaven.com, CC0):
   Download: HDRI skies, PBR textures, terrain materials
   Place in: Content/Environment/

=== STEP 4: Enable Nanite + Lumen + RayTracing ===
In UE5 Editor:
   Content Browser > select all imported Static Meshes
   Right click > Asset Actions > Bulk Edit > Property Matrix
   Set "Nanite Enabled" = True

   Project Settings > Rendering:
   Dynamic Global Illumination Method = Lumen
   Reflection Method = Lumen
   Shadow Map Method = Virtual Shadow Maps

   Edit > Project Settings > Platforms > Windows >
   Default RHI = DirectX 12
   Enable RayTracing = checked

   In Config/DefaultEngine.ini add under [SystemSettings]:
   r.RayTracing=1
   r.RayTracing.Shadows=1
   r.RayTracing.Reflections=1
   r.RayTracing.GlobalIllumination=1
   r.Lumen.DiffuseIndirect.Allow=1
   r.Lumen.Reflections.Allow=1
   r.Nanite=1

=== STEP 5: World Partition for open world ===
Convert the default map to World Partition:
   Tools > Convert Level > Enable World Partition
   Add Landscape actor (48km x 50km, 1009x1009 resolution)
   Sculpt terrain using ChimeraGlobe.h elevation data
   Add Ocean actor at Z=0m
   Add PCG volume for foliage spawning
   Add road splines following the road network

=== STEP 6: First playable run ===
Hit Play in the editor.
You should see the Nexus hub with the tower, plaza ring,
15 fast-travel stations, interactables, NPCs, and HUD.
Walk through a ring gate to fast-travel.
Or drive/walk across the landscape between regions.

=== TROUBLESHOOTING ===
Compile errors: add missing #include lines for engine classes.
Grey boxes everywhere: assets not downloaded yet — see Step 3.
No NPCs: check that GameMode is set to ChimeraGameModeBase.
No interactables: check that the HUD is rendering (Canvas-based).
Black screen: add a DirectionalLight to the level.
=== END SETUP GUIDE ===
